# Safe Save Sahittyo — Public Transparency Log

স্বপ্ন-কলম সাহিত্য পরিবারের **Safe Save Sahittyo** অ্যাপের স্বচ্ছতা লগ।

## এখানে কী আছে
- `log/entries.jsonl` — শুধু-যোগ-করা (append-only) এন্ট্রি: **লেখার SHA-256 হ্যাশ, সময়, স্বাধীন TSA টোকেনের তথ্য**। লেখক-পরিচয় বা লেখা নেই।
- `checkpoints/` — প্রতিটি চেকপয়েন্ট (লগের আকার + Merkle root + সময়), তার RFC 3161 টাইমস্ট্যাম্প (`.tsr`) এবং `history.jsonl`।
- `index.html` (GitHub Pages) — ব্রাউজারে হ্যাশ খুঁজে inclusion যাচাই।
- `tools/verify.py` — যে কেউ চালিয়ে পুরো লগের ধারাবাহিকতা (consistency) যাচাই করতে পারেন।

## কীভাবে কাজ করে
1. অ্যাপ লেখার প্রতিটি সংস্করণের হ্যাশে স্বাধীন RFC 3161 TSA-র টাইমস্ট্যাম্প নেয়।
2. সেই (হ্যাশ + সার্ভার-সময় + টোকেন) জনসমক্ষে `ledger` সংগ্রহে যায়।
3. এই রিপোর GitHub Actions প্রতি ঘণ্টায় নতুন এন্ট্রি `entries.jsonl`-এ **যোগ** করে, RFC 6962 Merkle tree বানায়, আগের চেকপয়েন্ট এখনো লগের প্রিফিক্স কিনা পরীক্ষা করে (না মিললে কাজ ব্যর্থ হয়), এবং নতুন চেকপয়েন্টে স্বাধীন TSA টাইমস্ট্যাম্প ও Sigstore (GitHub attestation) স্বাক্ষর বসায়।

## নিজে যাচাই করুন
```
git clone https://github.com/OWNER/REPO && cd REPO
python3 tools/verify.py
gh attestation verify checkpoints/latest.json --repo OWNER/REPO
```

## সৎ সীমাবদ্ধতা
- এই লগ প্রমাণ করে: **একটি নির্দিষ্ট হ্যাশ একটি নির্দিষ্ট সময়ের আগে থেকেই ছিল**। লেখার প্রকৃত স্রষ্টা কে, তার চূড়ান্ত আইনি প্রমাণ এটি একা দেয় না।
- লগ-অপারেটর রিপো মুছে বা ইতিহাস লিখে ফেললে তা ধরা পড়ে শুধু তখনই, যদি আগে কেউ ক্লোন বা চেকপয়েন্ট সংরক্ষণ করে থাকেন। তাই **ক্লোন/মিরর করে রাখতে** সবাইকে উৎসাহিত করা হচ্ছে। স্বাধীন TSA টাইমস্ট্যাম্প ও Sigstore লগ পুরনো চেকপয়েন্টের সময় নিজে থেকেই সংরক্ষণ করে।
- লগ ঘণ্টায় একবার হালনাগাদ হয়, তাই নতুন সংস্করণ লগে আসতে সর্বোচ্চ ~১ ঘণ্টা লাগে।
